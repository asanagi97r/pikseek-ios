## 怎么测

同一台机器（宿主机）、同一个账号、同一个网络、同一批视频，先 Piko 后 PikSeek，各测三遍取中位数。

1. 选 3–5 个有代表性的视频，记下各自的情况：

   | 代号 | 容器 / 编码 | 分辨率 | 大小 | 时长 | 有没有转码流 |
   | --- | --- | --- | --- | --- | --- |
   | A | | | | | |
   | B | | | | | |
   | C | | | | | |

2. Piko 没有性能浮层，耗时从它的日志里读（设置 → 关于 → 导出日志）。相关的行：
   - `Player: 打开：…` 到 `Player: 首帧就绪`：起播；
   - `Player: 拖动后画面走起来 N ms`：拖动；
   - 换集：点下一集的时刻到下一次 `首帧就绪`。
3. 每个视频做：冷启动打开一次；从 20% 拖到 80% 一次、再拖回 30% 一次；点一次下一集。
